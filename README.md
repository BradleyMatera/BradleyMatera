## Developer

I usually just call myself a **developer**.

I am strongest at taking an idea and pushing it toward a complete, usable experience. That can mean a frontend, API, authentication, database, deployment, cloud services, automation, or whatever else the project needs to work end to end.

I use AI heavily as part of that process. I use it to research, prototype, generate code, debug, compare approaches, write tests, and move through unfamiliar systems faster. I still make the product decisions, test the result, change what does not work, and learn the system as I go. I do **not** treat AI-generated implementation as proof that I personally have senior-level depth in every technology inside a repository.

That distinction matters to me. I have built a lot of software, but many of those builds started because I wanted to see whether I could make the entire thing work, not because I was already an expert in every layer.
